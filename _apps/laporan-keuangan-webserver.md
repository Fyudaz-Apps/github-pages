# Laporan Keuangan Webserver

This provides a React dashboard frontend configuration for the financial reports application. Built with Vite, React, and TypeScript.

## Getting Started

### Prerequisites
* Node.js (LTS version)
* npm or bun package manager

### Setup and Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
